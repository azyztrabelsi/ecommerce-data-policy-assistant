# Return Policy

> SIMULATED capstone content. This is not an actual Olist policy.

## 1. Return window
1.1 A customer may return an item within 14 days after the delivery date.
1.2 For defective items and wrong items, the window is 30 days after the delivery date.

## 2. Item condition
2.1 The item must be unused, in its original packaging, with all accessories.
2.2 Items damaged by the customer cannot be returned.

## 3. Return steps
3.1 The customer contacts support with the order ID and the reason.
3.2 Support approves or rejects the request within 2 business days.
3.3 After approval, the customer ships the item within 7 days using the provided label.
3.4 The seller inspects the item within 5 business days, then the refund is started (see POL-REFUND-001).

## 4. Costs
4.1 The customer pays return shipping for change-of-mind returns.
4.2 The seller pays return shipping for defective, wrong or damaged items.

## 5. Exceptions
5.1 Perishable items (food and drink) cannot be returned unless they arrive damaged.
5.2 Orders not yet delivered cannot be returned; use POL-CANCEL-001 instead.
